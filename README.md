# Nova

Nova is a personal AI assistant for iPhone: think JARVIS's dry wit crossed with a sarcastic best friend who is secretly very good at her job. She's a web app you add to your Home Screen. No App Store needed.

**Open Nova:** https://mo0n238.github.io/nova/ in Safari, then Share → Add to Home Screen.

**About Nova (website):** https://mo0n238.github.io/nova/about.html

## What she does
- **Talk or type**: chat, quick answers, instant math, weather, tap-to-talk voice
- **Tasks & schedule**: to-dos, events, reminders and timers (notifications even when Nova is closed)
- **Memory**: remembers what you tell her
- **Feed**: posts from friends and people you follow, with comments and reposts
- **Connect**: invite-only, 18+ friends space: friends, follows, chat and leaderboards, plus block, report and picture checks
- **Games**: ⭐ Starhop (platformer, 4 heroes, 3 worlds), 🏃 Nova Run and 🧩 Nova Blocks
- **What's New**: every update and how long ago it came out

## Files
| File | What it is |
|---|---|
| `index.html` | Nova herself (the whole app) |
| `starhop.html` | Starhop, Nova's main game |
| `about.html` | Nova's website, with a live member counter |
| `sw.js` | Lets Nova open fast and offline, and get notifications |
| `manifest.webmanifest`, icons | Home Screen app setup |
| `cloud/` | Nova Cloud server (runs on Cloudflare) |
| `music.html`, `heroes.html`, `worlds.html` | Preview pages for the soundtrack and game art |
